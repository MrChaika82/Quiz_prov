# Quiz Project (C++)

## Описание
Консольное приложение-викторина, разработанное на C++.  
Проект позволяет проходить тесты с несколькими вариантами ответов, вводить ответы через консоль и получать результат в конце.

Также реализован модуль автоматических тестов с использованием Google Test.

---

## Возможности

- Загрузка и хранение вопросов
- Поддержка нескольких вариантов ответов
- Проверка корректности ввода пользователя
- Обработка ошибок ввода (буквы, пустой ввод, неверные числа)
- Подсчёт результата
- Автоматические тесты (Google Test)

---

## Структура проекта

- `main.cpp` — запуск квиза
- `Quiz.h / Quiz.cpp` — логика хранения вопросов
- `Question.h / Question.cpp` — модель вопроса
- `QuizEngine` — обработка игрового процесса
- `FileLoader` — загрузка вопросов из файла
- `QuizTests` — модульные тесты с использованием Google Test
---

## Формат файла вопросов

Вопросы хранятся в текстовом файле в формате:

```text
Вопрос|Ответ1|Ответ2|Ответ3|Правильный индекс
```

Пример:

```
Сколько будет 2+2?|3|4|5|2
Столица Франции?|Берлин|Париж|Рим|2
```
---

## Используемые технологии

- C++
- STL (vector, string)
- Google Test
- Visual Studio

---

## Как запустить

1. Открыть проект в Visual Studio
2. Собрать решение (Ctrl + Shift + B)
3. Запустить `QuizProject` для игры
4. Запустить `QuizTests` через Test Explorer для тестов
